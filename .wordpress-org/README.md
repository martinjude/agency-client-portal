# WordPress.org assets

Images in this folder are deployed to the plugin's SVN `assets/` directory, not shipped in the plugin ZIP.

Expected files:

| File | Size | Use |
|---|---|---|
| `banner-772x250.png` | 772×250 | Plugin page banner |
| `banner-1544x500.png` | 1544×500 | Banner (retina) |
| `icon-128x128.png` | 128×128 | Plugin icon |
| `icon-256x256.png` | 256×256 | Plugin icon (retina) |
| `screenshot-1.png` … | any | Screenshots, matching `== Screenshots ==` in `readme.txt` |

See https://developer.wordpress.org/plugins/wordpress-org/plugin-assets/
